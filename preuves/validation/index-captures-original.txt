## Portée des mesures

Les captures 05 sont historiques : la capture des hooks affichait six contrats. Le verify final en affiche neuf. La couverture V8 compte les modules chargés et les fonctions nommées du code transpilé ; ce n’est pas un taux de lignes/branches TypeScript. Les six mutations sont un échantillon déclaré, pas un score exhaustif.

`03-npm-audit.json` conserve les vulnérabilités de l’outillage non mis à jour sans autorisation. Les preuves MCP distinguent une réponse HTTP, une variable absente et une initialisation MCP réellement réalisée. Aucun secret n’est affiché.

Le serveur reproductible [outils/preuves.py](outils/preuves.py) affiche les contrôles et la trace locale. Le lancement du mode verify ou coverage exécute réellement le contrôle ; le mode session lit uniquement la trace. Le serveur est local et n’envoie aucune instruction aux agents.

Le dossier de preuves est livré avec le dépôt complet. `git diff` seul n’inclut pas les nouveaux fichiers non suivis ; les copies de sources et les inventaires assurent leur conservation. Aucun commit ni push n’a été effectué.
